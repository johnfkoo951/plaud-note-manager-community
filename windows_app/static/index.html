작업 대기 중

1. 연결

본인 계정에서 복사한 Plaud API cURL만 입력하세요. 인증값은 Windows 전용 보안 저장소에 보관됩니다.

2. 가져오기

목록 동기화는 제목과 날짜만 가져옵니다.

전사·요약 백필은 아직 저장하지 않은 전체 내용을 이 PC로 내려받습니다. 공용 PC에서는 실행하지 마세요.

3. 자동 폴더 정리

내 Plaud 계정에 이미 있는 폴더만 후보로 사용합니다. 최근 미분류 녹음 최대 200개를 먼저 미리보고 선택한 항목만 Plaud Cloud에 적용합니다. AI 요청은 미리보기당 최대 20회입니다.

이동 제안

되돌리기 전에는 적용 직후의 폴더 상태가 Plaud Cloud와 이 PC에 그대로인지 전체 항목을 먼저 확인합니다.

4. 외부 서비스 설정

OAuth 방식은 해당 공급자 CLI에 먼저 로그인한 뒤 사용합니다. 이 앱은 OAuth 토큰을 읽거나 복사하거나 저장하지 않습니다.

이 제한판의 경계

  • Plaud Cloud 폴더 이동은 미리보기에서 선택해 적용할 때만 씁니다.
  • 웹 로그인과 오디오 재생은 없습니다.
  • 선택한 AI에는 확인 후 폴더명과 캐시된 녹음 텍스트를 보낼 수 있습니다.
  • ElevenLabs 전사는 확인 후 오디오를 업로드하며 유료 크레딧을 쓸 수 있습니다.
  • Obsidian이나 브라우저 프로필은 탐색하지 않습니다.
  • 백필은 버튼을 눌렀을 때만 시작합니다.
